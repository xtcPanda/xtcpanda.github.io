# Moaaz Akram — interactive portfolio

A bilingual miniature studio for client delivery and operations, work stories, personal projects and writing.

Live portfolio: https://xtcpanda.github.io/

Static HTML, CSS and JavaScript, with Three.js. No build step, accounts or analytics. Open the Mac or wall board for Projects & Ideas. The browser demonstrations use fictional data and are separate from the original projects.
